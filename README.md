# Java Equation Solver

This project is a simple Java program that solves linear and quadratic equations.

## Description

The program uses a class called `EquationSolver` with two methods:

- **solveLinear():** Solves linear equations (ax + b = 0).
- **solveQuadratic():** Solves quadratic equations (ax² + bx + c = 0).

## Features

- Solves linear equations.
- Solves quadratic equations using the discriminant (Delta).
- Handles equations with no solution or infinitely many solutions.
- Displays real roots of quadratic equations.
- Takes input from the user.

## How to Run

1. Open the `EquationSolverDemo.java` file.
2. Run the program using Java.
3. Choose the equation type (1 or 2).
4. Enter the coefficients.
5. View the result.

## Example

**Linear Equation:**

Input: a = 2, b = 4

Output: x = -2.0

**Quadratic Equation:**

Input: a = 1, b = -5, c = 6

Output: x1 = 3.0, x2 = 2.0
